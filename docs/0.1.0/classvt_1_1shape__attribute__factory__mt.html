Detailed Description

template<typename shape_type, typename tool_type, typename... tool_types>
class vt::shape_attribute_factory_mt< shape_type, tool_type, tool_types >

A shape attribute factory that supports multiple tools. The first tool type is specified as a template parameter, while the rest are specified as variadic template parameters. All tool types must derive from ui::toolbar_tool and be default constructible.
