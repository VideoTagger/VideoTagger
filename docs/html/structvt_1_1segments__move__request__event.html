Detailed Description

Event triggered when trying to move one or more segments.

The segments are not actually moved yet and the event can be used to modify or cancel the move. After processing this event, a segments_try_move_result_event should be dispatched with approved set to true if the move should be applied or false if the move should be cancelled.
