Detailed Description

Event triggered when trying to insert a segments.

The segment is not actually inserted yet and the event can be used to modify or cancel the insertion. After processing this event, a segments_try_insert_result_event should be dispatched with approved set to true if the insertion should be applied or false if the insertion should be cancelled.
