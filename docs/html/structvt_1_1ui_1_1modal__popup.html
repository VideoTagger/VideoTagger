Parameters
[in]idThe id for the popup
[in,out]openIf boolean pointer is passed, it will be set to true when the popup is open or false otherwise. If std::nullopt is passed, the popup will still be able to be closed but you won't know the state of the popup. If nullptr is passed, the popup won't be able to be closed.
