void vt::wand_tool::render_properties ( )
overridevirtual

Renders the properties of the tool in the properties window.

Only relevant if property_column_count() returns a value greater than 0. Each tool should call ImGui::TableNextColumn() before rendering the content of each column. The number of columns is determined by the value returned by property_column_count().
